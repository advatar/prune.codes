# CR-006 — Context7 Integration (Codex + OpenCode first) + Optional Docs Provider in Prune

## Summary
Integrate **Context7** into Prune in two complementary ways:

1) **Agent-side (recommended baseline):** Install **Context7 MCP** alongside **Prune MCP** for Codex and OpenCode using `ce integrate ... --with context7`.  
2) **Engine-side (optional, best for smaller models):** Add a **Docs Provider** inside Prune that can query Context7’s API and inject a *small, bounded* “External Reference Docs” section into packs.

This enables:
- fewer outdated API guesses
- faster inception with correct best practices
- better performance on evolving stacks (React/Vite/Tailwind/Supabase)

---

## Goals
- **Codex + OpenCode first** (primary targets for integration presets and instructions).
- Keep Context7 inclusion **strictly budgeted** and **privacy-safe**:
  - send only library names/IDs and short natural language queries
  - never send proprietary code
- Make docs injection **opt-in** and **strategy-controlled**.
- Add aggressive caching to minimize latency and cost.

---

## Non-goals
- Hard dependency on Context7 for core Prune operation (Prune must work offline).
- Agent-specific plugin development for Context7 (we rely on MCP + instructions).
- Ingestion of full documentation corpora locally (Context7 is the source-of-truth).

---

## Part A — Agent-side integration (Codex + OpenCode)

### A1) Extend `ce integrate codex` and `ce integrate opencode`
Add flag:
- `--with context7` (or `--with docs=context7`)

Behavior:
- Install/patch Prune MCP as today.
- Additionally install/patch **Context7 MCP** server config and instruction text.

### A2) Codex configuration
Codex supports MCP servers configured in `~/.codex/config.toml` or `.codex/config.toml`.

For `--with context7`, generate a *project-scoped* `.codex/config.toml` snippet that includes two MCP servers:

```toml
[mcp_servers.prune]
command = "ce"
args = ["mcp", "serve"]
cwd = "."
enabled = true
startup_timeout_sec = 20
tool_timeout_sec = 60

[mcp_servers.context7]
command = "npx"
args = ["-y", "@upstash/context7-mcp"]
enabled = true
startup_timeout_sec = 20
tool_timeout_sec = 60
```

If `CONTEXT7_API_KEY` is present in the environment, document how to pass it.
(Do not attempt to write secrets into config by default.)

### A3) OpenCode configuration
OpenCode supports MCP servers in `opencode.json` under `mcp`.

For `--with context7`, patch `.opencode/opencode.json`:

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "prune": {
      "type": "local",
      "command": ["ce", "mcp", "serve"],
      "enabled": true,
      "timeout": 20000
    },
    "context7": {
      "type": "remote",
      "url": "https://mcp.context7.com/mcp",
      "enabled": true,
      "headers": {
        "Authorization": "Bearer ${CONTEXT7_API_KEY}"
      }
    }
  }
}
```

If env var expansion is not supported in a user’s environment, document the manual step.

### A4) Instruction files (AGENTS.md first)
Update the generated `AGENTS.md` template when `--with context7` is enabled:

Add a short rule block:

- Use Prune for code context packs.
- Use Context7 for external library docs.
- Before writing new code that touches external APIs:
  - call Context7 to fetch the minimal relevant snippet
  - then proceed with Prune pack + edits

Keep it concrete and budget-conscious.

## Part B — Engine-side docs provider (optional)

### B1) New config file: `.prune/docs.json`
This controls if Prune itself calls Context7 API.

```jsonc
{
  "version": 1,
  "providers": {
    "context7": {
      "enabled": false,
      "api_base": "https://context7.com",
      "api_key_env": "CONTEXT7_API_KEY",
      "max_tokens": 800,
      "k": 4,
      "cache_dir": ".ce/docs-cache/context7",
      "cache_ttl_days": 7,
      "only_for_intents": ["inception", "integration", "dependency_error"],
      "deny_send_code": true
    }
  }
}
```

### B2) New crate: `crates/ce-docs`
Responsibilities:
- Provider trait: `DocsProvider`
- Context7 client implementation:
  - search library: `GET /api/v2/libs/search?libraryName=...&query=...`
  - fetch context: `GET /api/v2/context?libraryId=...&query=...`
- Cache layer (disk):
  - `libs_search` results keyed by (libraryName, query)
  - `context` results keyed by (libraryId, query, type)
- Token budgeting + truncation:
  - enforce `max_tokens`
  - store approximate tokens for each snippet

### B3) Pack integration
Add optional pack section:

**“External Reference Docs (Context7)”**

Rules:
- Only include docs if:
  - pack intent matches `only_for_intents`
  - query mentions or import scan suggests external lib usage
- Always cap:
  - `max_tokens` for docs section
  - `k` snippets

#### Suggested pack pipeline changes
1) Build normal candidate set (repo fragments) as today.
2) If docs enabled and intent allows:
   - detect library candidates:
     - from imports in seed fragments
     - from dependencies in `package.json` / `Cargo.toml` / `Package.swift` (if present)
     - from user query keywords
   - choose top 1–2 libraries
   - call Context7 for each:
     - library search
     - context fetch (txt format)
   - add returned text as **doc fragments** with kind `ref_doc`
3) Continue pruning + connected subgraph selection.

### B4) Privacy rules
- Never send code.
- Queries must be natural language (e.g., “How to create Supabase Edge Function with auth”).
- If the user query includes large code blocks, strip them before sending to Context7.

### B5) Failure modes
- Missing API key / rate limit:
  - return “docs unavailable” with a concise reason in debug output
  - do not fail pack
- Network down:
  - skip docs section

## Implementation details (code skeleton)

### `crates/ce-docs/src/lib.rs`
```rust
use anyhow::Result;

#[derive(Clone, Debug)]
pub struct DocsSnippet {
    pub provider: String,
    pub library: String,
    pub title: String,
    pub text: String,
    pub approx_tokens: usize,
    pub source_url: Option<String>,
}

#[derive(Clone, Debug)]
pub struct DocsQuery {
    pub intent: String,
    pub libraries: Vec<String>,
    pub query: String,
    pub k: usize,
    pub max_tokens: usize,
}

pub trait DocsProvider: Send + Sync {
    fn name(&self) -> &str;
    fn enabled(&self) -> bool;
    fn fetch(&self, q: &DocsQuery) -> Result<Vec<DocsSnippet>>;
}
```

### `crates/ce-docs/src/context7.rs` (HTTP client)
Use `reqwest` blocking or async (prefer async if the rest is async).

Pseudo:
- search lib ID
- fetch context

### Cache
Disk cache path:
- `.ce/docs-cache/context7/`

Key naming:
- sha256 of request params (provider + endpoint + normalized query)

Add optional tool:
- `docs.fetch` (thin wrapper that fetches docs via provider config)

This is useful if an agent wants docs but prefers Prune to coordinate caching and privacy.

  - Context7 (external docs)

  - respects privacy constraints
  - enforces strict token budget

  - how to use Context7 effectively (small targeted queries)
