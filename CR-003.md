# CR-003 — LSP On‑Demand Semantic Resolver (Prune / ce pack)

## Summary
Add **optional, on-demand LSP (Language Server Protocol) support** to Prune so the context engine can resolve **definitions, type definitions, implementations, and usages** with compiler-grade accuracy **without** replacing the existing AST-first pipeline.

This is designed to unlock **smaller/cheaper LLMs** by producing tighter, more correct packs:

- Resolve **“No Unbound Names”** using `textDocument/definition` (and `typeDefinition`) when heuristic matching is uncertain.
- Resolve TSX `<Component />` tags to their real definition (including `paths` aliases).
- Resolve SwiftUI state/types across extensions.
- Resolve Rust definitions through traits/impls/macros (where syntax-only approaches struggle).

The LSP layer is:
- **Optional**: disabled by default
- **Lazy**: starts servers only when needed
- **Bounded**: strict caps and timeouts
- **Cacheable**: stores LSP-derived edges for reuse in future packs

---

## Goals
1. Implement a **minimal LSP client** in Rust (stdio JSON-RPC) and integrate it into `ce pack` as a *semantic oracle*.
2. Add CLI tooling to make LSP usable and debuggable:
   - `ce lsp doctor`
   - `ce lsp resolve-definition`
   - `ce lsp resolve-type`
3. Add a repo-level config for server commands and capability toggles:
   - `.prune/lsp.json`
4. Integrate with existing strategies:
   - **Structured Signals** → seed file/line → LSP definition expansions
   - **No Unbound Names** → LSP fallback when missing defs remain
   - **Connected Subgraph Packing** → LSP edges tighten the graph
5. Persist results as high-confidence edges with origin `"lsp"`.

---

## Non-goals
- Full index-time LSP ingestion for entire repo (we may add later as an optional “enrich” mode).
- Implementing the LSP spec beyond what we need (keep surface small and stable).
- Handling all LSP message types and dynamic registrations (we will use conservative capabilities).
- Remote LSP servers / over TCP (stdio only in this CR).

## Architecture

### New crate: `crates/ce-lsp`
A minimal JSON-RPC + LSP client over stdio.

**Modules**
- `transport.rs` — reads/writes framed LSP messages (`Content-Length` headers)
- `client.rs` — request/response handling, pending map, id generation
- `types.rs` — re-export `lsp_types` and helpers
- `session.rs` — per-workspace server process, open-doc tracking, versioning
- `config.rs` — loads `.prune/lsp.json` and validates
- `doctor.rs` — implements doctor checks

**Dependencies**
- `tokio` (process + async IO)
- `serde`, `serde_json`
- `lsp-types`
- `anyhow`
- (optional) `globset` for file globs

### LSP session strategy
- One LSP server per language **per workspace** (repo root).
- Start lazily on first request.
- Reuse sessions across multiple packs (MCP server + PruneApp can keep them warm).

### Threading model
- A read loop task that parses messages and routes responses.
- A write loop task that writes outgoing messages.
- Requests return a `Future` that resolves via `oneshot`.

### `crates/ce-lsp/src/transport.rs`
```rust
use anyhow::{anyhow, Context, Result};
use tokio::io::{AsyncReadExt, AsyncWriteExt};
use tokio::process::{ChildStdin, ChildStdout};

pub struct LspTransport {
    stdin: ChildStdin,
    stdout: ChildStdout,
}

impl LspTransport {
    pub fn new(stdin: ChildStdin, stdout: ChildStdout) -> Self {
        Self { stdin, stdout }
    }

    pub async fn write_message(&mut self, json: &str) -> Result<()> {
        let bytes = json.as_bytes();
        let header = format!("Content-Length: {}\r\n\r\n", bytes.len());
        self.stdin.write_all(header.as_bytes()).await?;
        self.stdin.write_all(bytes).await?;
        self.stdin.flush().await?;
        Ok(())
    }

    pub async fn read_message(&mut self) -> Result<String> {
        // Read headers until \r\n\r\n
        let mut header_buf = Vec::new();
        loop {
            let mut b = [0u8; 1];
            let n = self.stdout.read(&mut b).await?;
            if n == 0 {
                return Err(anyhow!("LSP stdout closed"));
            }
            header_buf.push(b[0]);
            if header_buf.ends_with(b"\r\n\r\n") {
                break;
            }
            if header_buf.len() > 16 * 1024 {
                return Err(anyhow!("LSP header too large"));
            }
        }

        let header = String::from_utf8_lossy(&header_buf);
        let mut content_len: Option<usize> = None;
        for line in header.lines() {
            let line = line.trim();
            if let Some(rest) = line.strip_prefix("Content-Length:") {
                content_len = Some(rest.trim().parse::<usize>().context("bad Content-Length")?);
            }
        }
        let len = content_len.ok_or_else(|| anyhow!("missing Content-Length"))?;
        let mut body = vec![0u8; len];
        self.stdout.read_exact(&mut body).await?;
        let s = String::from_utf8(body).context("LSP body not utf-8")?;
        Ok(s)
    }
}
```

### `crates/ce-lsp/src/client.rs`
```rust
use anyhow::{anyhow, Result};
use serde_json::Value;
use std::collections::HashMap;
use std::sync::atomic::{AtomicU64, Ordering};
use tokio::sync::{mpsc, oneshot, Mutex};
use std::sync::Arc;

#[derive(Clone)]
pub struct LspClient {
    next_id: Arc<AtomicU64>,
    pending: Arc<Mutex<HashMap<u64, oneshot::Sender<Value>>>>,
    tx: mpsc::Sender<String>,
}

impl LspClient {
    pub fn new(tx: mpsc::Sender<String>) -> Self {
        Self {
            next_id: Arc::new(AtomicU64::new(1)),
            pending: Arc::new(Mutex::new(HashMap::new())),
            tx,
        }
    }

    pub async fn request(&self, method: &str, params: Value) -> Result<Value> {
        let id = self.next_id.fetch_add(1, Ordering::Relaxed);
        let (sx, rx) = oneshot::channel();
        self.pending.lock().await.insert(id, sx);

        let msg = serde_json::json!({
            "jsonrpc": "2.0",
            "id": id,
            "method": method,
            "params": params
        });

        self.tx.send(msg.to_string()).await.map_err(|_| anyhow!("LSP tx closed"))?;
        let resp = rx.await.map_err(|_| anyhow!("LSP response dropped"))?;
        Ok(resp)
    }

    pub async fn notify(&self, method: &str, params: Value) -> Result<()> {
        let msg = serde_json::json!({
            "jsonrpc": "2.0",
            "method": method,
            "params": params
        });
        self.tx.send(msg.to_string()).await.map_err(|_| anyhow!("LSP tx closed"))?;
        Ok(())
    }

    pub async fn on_response(&self, raw: Value) -> Result<()> {
        let id = raw.get("id").and_then(|v| v.as_u64()).ok_or_else(|| anyhow!("missing id"))?;
        if let Some(tx) = self.pending.lock().await.remove(&id) {
            let _ = tx.send(raw);
        }
        Ok(())
    }
}
```

### `crates/ce-lsp/src/session.rs`
```rust
use anyhow::{Context, Result};
use tokio::process::Command;
use tokio::sync::mpsc;
use tokio::time::{timeout, Duration};
use serde_json::Value;

use crate::transport::LspTransport;
use crate::client::LspClient;

pub struct LspSession {
    pub client: LspClient,
    tx: mpsc::Sender<String>,
}

impl LspSession {
    pub async fn start(command: &[String], root_uri: &str, init_timeout_ms: u64) -> Result<Self> {
        let mut cmd = Command::new(&command[0]);
        cmd.args(&command[1..]);
        cmd.stdin(std::process::Stdio::piped());
        cmd.stdout(std::process::Stdio::piped());
        cmd.stderr(std::process::Stdio::inherit());

        let mut child = cmd.spawn().context("failed to spawn lsp server")?;
        let stdin = child.stdin.take().context("no stdin")?;
        let stdout = child.stdout.take().context("no stdout")?;

        let (tx, mut rx) = mpsc::channel::<String>(256);
        let mut transport = LspTransport::new(stdin, stdout);

        let client = LspClient::new(tx.clone());

        // writer task
        let mut transport_w = transport;
        let client_clone = client.clone();
        tokio::spawn(async move {
            loop {
                tokio::select! {
                    Some(msg) = rx.recv() => {
                        let _ = transport_w.write_message(&msg).await;
                    }
                    else => break
                }
            }
        });

        // reader task
        let client_clone2 = client_clone.clone();
        let mut transport_r = transport_w; // NOTE: in real code split transport into separate stdin/stdout halves
        // For CR: implement by creating two transports or split in transport struct.

        // Initialize
        let init_params = serde_json::json!({
            "processId": std::process::id(),
            "rootUri": root_uri,
            "capabilities": {
                "textDocument": {
                    "definition": { "dynamicRegistration": false },
                    "typeDefinition": { "dynamicRegistration": false },
                    "implementation": { "dynamicRegistration": false },
                    "references": { "dynamicRegistration": false }
                }
            }
        });

        let resp = timeout(Duration::from_millis(init_timeout_ms), client.request("initialize", init_params)).await
            .context("initialize timeout")??;

        // send initialized
        client.notify("initialized", serde_json::json!({})).await?;

        Ok(Self { client, tx })
    }
}
```

> NOTE: In the real implementation, **split transport read and write** (store stdin and stdout separately or use two structs) so read loop and write loop can run concurrently without borrowing conflicts.

## Integration with `ce pack`

### Pack-time semantic fallback (recommended)
Add an optional “semantic resolver” layer:

1. Build initial candidate pack using existing pipeline (AST + embeddings + graphs).
2. Run **No Unbound Names**:
   - extract referenced identifiers + best occurrence spans (file + line + col)
3. If missing symbols remain and `--lsp auto|on`:
   - call `textDocument/definition` at the occurrence position(s)
   - map returned locations to fragments (or create slices)
   - add them to pack as signatures or minimal slices
4. Persist edges with `origin="lsp"` and `confidence=1.0`:
   - in SQLite: `edges(origin, confidence, weight)`
   - in SurrealDB: `RELATE ... SET origin="lsp", confidence=1.0`

### Where to hook (pseudocode)
```rust
if lsp_mode != Off {
    let unresolved = support_closure.unresolved_symbols();
    let mut requests = 0;

    for sym in unresolved.iter().take(max_lsp) {
        if let Some(occ) = sym.best_occurrence() {
            // LSP definition request
            let def_locs = lsp.resolve_definition(&occ.path, occ.line, occ.col).await?;
            // Map locations to fragments
            let frags = map_locations_to_fragments(def_locs)?;
            pack.add_support(frags);
            requests += 1;
            if requests >= max_lsp { break; }
        }
    }
}
```

## LSP request details (minimum)
We implement these methods:

- `initialize`
- `initialized` (notify)
- `textDocument/didOpen` (notify) — send full text for files we query
- `textDocument/definition`
- `textDocument/typeDefinition`
- (optional, later) `textDocument/implementation`
- (optional, later) `textDocument/references`

### Document open policy
To resolve definition at `(file, line, col)`:
1) ensure session started
2) if file not opened:
   - read file text
   - send `didOpen` with version = 1
3) send definition request

We do not implement `didChange` initially; instead:
- if file changed on disk since open, we may re-open (close + open) for correctness
- later we add incremental change support

---

## Caching policy
Cache LSP results at two layers:

1) **In-memory per session**:
   - `(file_hash, line, col, method) -> locations`
   - TTL: one pack run

2) **Persistent edge cache** (optional but recommended):
   - store “definition edge” for `(ref_frag -> def_frag)` with `origin=lsp`
   - next pack can reuse it without calling LSP

## Acceptance Criteria
1. `ce lsp doctor` works and clearly reports missing tools/markers.
2. `ce lsp resolve-definition` returns at least one location on known fixtures.
3. `ce pack --lsp auto` improves:
   - fewer unresolved symbols (lower `unbound_symbol_count`)
   - higher precision (smaller support closure) for TSX and Rust
4. Strict safety:
   - cap requests (`max_requests_per_pack`)
   - enforce timeouts (`default_timeout_ms`)
   - never block pack indefinitely
5. Works without LSP installed (feature gracefully disabled).
